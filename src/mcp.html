Intégration IA

Codas pour ton IA

Connecte Claude Code, Cursor, ChatGPT et autres assistants IA au catalogue Codas via MCP. Découvre des composants SwiftUI et intègre-les directement dans tes projets sans quitter ton éditeur.

1 Génère ta clé API

Ouvre l'app Codas sur ton iPhone, iPad ou Mac, va dans Profil → Clés API et appuie sur Générer une nouvelle clé. La clé s'affiche une seule fois — copie-la immédiatement.

Format : ta clé commence par codas_pk_ et fait une quarantaine de caractères. Tu peux générer jusqu'à 10 clés actives en parallèle (une par machine ou par outil).

2 Ajoute Codas dans ton client IA

Choisis ton client et copie la commande ou la config. Remplace codas_pk_xxx par ta vraie clé.

Une seule commande dans ton terminal :

claude mcp add codas https://mcp.codaslibrary.app/mcp \ --transport http \ --header "Authorization: Bearer codas_pk_xxx"

Vérifie que Codas apparaît bien :

claude mcp list

Ajoute le serveur dans ~/.cursor/mcp.json :

{ "mcpServers": { "codas": { "url": "https://mcp.codaslibrary.app/mcp", "headers": { "Authorization": "Bearer codas_pk_xxx" } } } }

Redémarre Cursor pour charger la config.

Ajoute dans ~/.codeium/windsurf/mcp_config.json :

{ "mcpServers": { "codas": { "serverUrl": "https://mcp.codaslibrary.app/mcp", "headers": { "Authorization": "Bearer codas_pk_xxx" } } } }

Dans ChatGPT Desktop : Settings → Beta features → Model Context Protocol. Ajoute un nouveau connecteur :

Name: codas URL: https://mcp.codaslibrary.app/mcp Headers: Authorization: Bearer codas_pk_xxx

Dans les Settings de Zed (cmd+,) :

{ "context_servers": { "codas": { "command": null, "url": "https://mcp.codaslibrary.app/mcp", "headers": { "Authorization": "Bearer codas_pk_xxx" } } } }

Tout client MCP supportant le transport HTTP fonctionne. Les paramètres à fournir :

URL : https://mcp.codaslibrary.app/mcp Transport : HTTP (Streamable) Auth : Bearer codas_pk_xxx (header Authorization)

Le serveur supporte le protocole MCP 2025-06-18.

3 Teste avec ton assistant

Lance une conversation et essaie ces prompts. L'IA appellera automatiquement les outils Codas.

Liste-moi les composants populaires de Codas.
Recommande-moi un composant pour un graphique.
Trouve un bouton avec effet glass et intègre-le dans MyView.swift.
Récupère le code de MiniBarChart.

Outils disponibles

search_components

Recherche par mots-clés. Si tu donnes une phrase multi-mots, on tokenise automatiquement et on cherche chaque mot. Retourne uniquement les métadonnées (pas le code).

get_component

Récupère le code SwiftUI complet + les instructions d'intégration + les dépendances. Pour les composants payants non obtenus, l'IA est invitée à orienter l'utilisateur vers l'app pour l'achat.

recommend_component

Prend un besoin en langage naturel (FR ou EN), extrait des mots-clés et propose le top 5 composants les plus pertinents avec un score de match. Idéal quand tu ne connais pas le nom exact.

FAQ

Mes composants payants sont-ils accessibles via MCP ?

Oui — tant que tu les as obtenus dans l'app au préalable. Le serveur vérifie tes achats avant de livrer le code. Pour les payants non obtenus, l'IA reçoit un message expliquant qu'il faut passer par l'app.

Comment révoquer une clé compromise ?

Dans l'app Codas → Profil → Clés API, tape sur l'icône poubelle de la clé concernée. La révocation est immédiate côté serveur.

Quelles données sont envoyées au serveur MCP ?

Uniquement les paramètres des outils appelés par l'IA (mots-clés de recherche, UUIDs de composants). Aucun contenu de ton projet local n'est transmis — l'IA filtre côté éditeur.

Le code source du serveur MCP est-il public ?

Oui, ouvert sur github.com/DevTipsy/codas-mcp. Tu peux auditer ce qui est fait de ta clé et même héberger ton propre instance si tu le souhaites.
